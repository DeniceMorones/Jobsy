# Evidencias de QA

Este directorio contiene evidencias representativas de la ejecución
de pruebas del MVP.

## Convención de nombres

Las evidencias utilizarán el formato:

`EV-XXX-descripcion`

Ejemplos:

- `EV-001-job-creado.txt`
- `EV-002-job-ejecutado.txt`
- `EV-003-cancelacion.png`

Las evidencias deberán estar relacionadas con los casos de prueba
correspondientes mediante la matriz de trazabilidad.
