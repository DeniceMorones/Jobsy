# Casos de prueba — MVP Avance 1

Este documento contiene los casos de prueba definidos para verificar
las funciones del MVP de Jobsy.

## Estados

Cada caso puede encontrarse en uno de los siguientes estados:

- `PENDING`: todavía no ejecutado.
- `PASS`: resultado conforme a lo esperado.
- `FAIL`: resultado diferente al esperado.
- `BLOCKED`: no fue posible ejecutar la prueba.
