# Quality Assurance

Este directorio contiene la documentación relacionada con las actividades
de pruebas y aseguramiento de calidad de Jobsy.

## Objetivo

Documentar la estrategia de pruebas, los casos de prueba, la trazabilidad
entre requisitos y pruebas, así como las evidencias generadas durante la
verificación del MVP.

## Documentos

- `test-plan.md`: alcance y estrategia general de pruebas.
- `test-cases.md`: definición y resultados de los casos de prueba.
- `traceability-matrix.md`: relación entre requisitos, pruebas y evidencias.
- `ai-usage.md`: registro representativo del uso de herramientas de IA
  durante las actividades de QA.

## Estado actual

La documentación corresponde al MVP del primer avance de Jobsy.

El alcance actual considera la ejecución local de trabajos y no contempla
todavía operación remota.
